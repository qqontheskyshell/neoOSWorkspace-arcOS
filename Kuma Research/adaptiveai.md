# Adaptive — Full Platform Documentation

> AI agents that connect your tools and get work done.

Adaptive helps you automate workflows and build software using plain English. Tell Adaptive what you need, connect the tools you already use, and it builds and runs the system for you.

## What Is Adaptive?

Adaptive is an AI agent platform for people and teams. You describe the outcome you want, and Adaptive connects services like Gmail, Slack, Google Sheets, and Calendar, then generates the workflow or app and runs it end to end.

### What You Can Do With Adaptive

- **Automate workflows across your tools**: Handle support inboxes, run outreach, sync data, generate reports, and schedule recurring tasks.
- **Build full applications in conversation**: Create dashboards, internal tools, CRMs, booking systems, and other custom software without manual setup.
- **Run AI-powered operations**: Analyze documents, generate content and media, classify data, and power assistants with built-in AI models.
- **Launch quickly and iterate anytime**: Start in minutes, then refine behavior by describing changes in plain English.

### How It Works

1. **Describe what you need**: Tell Adaptive what you want to build or automate in plain English.
2. **Connect your tools**: Link services like Gmail, Slack, Google Sheets, and Calendar.
3. **Launch your agent**: Adaptive builds and runs the workflow or app, and you can adjust it anytime by describing what to change.

## Core Capabilities

### App Building (Durable Software)

Describe any tool, dashboard, or application in plain English. Adaptive generates the full-stack code and deploys it.

**What you get:**
- Real databases with schemas tailored to your use case
- Frontend UI with tables, forms, charts, dashboards, and interactive components
- Backend API endpoints with business logic
- User authentication (email, phone, or social login)
- Role-based access control
- Custom domains
- Responsive design that works on desktop and mobile

**Examples of what people build:**
- Wholesale order management systems for small businesses
- Personal finance trackers that sync with bank accounts via Plaid
- Workout plan generators that pull data from Whoop
- Client CRMs that sync with Gmail and Google Calendar
- Internal tools for customer support teams
- Project dashboards that aggregate data from multiple sources

### One-Off Task Execution

Ask Adaptive to perform tasks directly — no app needed. Results are delivered in real time.

**Examples:**
- "Research the top 10 competitors in the meal-kit delivery space and summarize their pricing"
- "Analyze this spreadsheet and create a summary report"
- "Extract all action items from this meeting transcript"
- "Calculate the compound interest on a $50,000 investment at 7% over 20 years"
- "Summarize this PDF and highlight the key legal terms"

### Scheduled Agents

Create recurring automations that run on a schedule — daily, weekly, or at custom intervals.

**Examples:**
- Daily morning briefings delivered to your inbox with calendar, weather, and top news
- Weekly expense reports generated from connected bank accounts
- Nightly summaries of sales data from Square populating a Google Sheet
- Monthly invoice generation and email delivery

### AI Generation

Built-in access to multiple AI models with no API keys to manage:

- **Text generation** (Gemini, GPT, Claude): Summarization, content creation, data extraction, classification, translation
- **Image generation**: Create images from text descriptions
- **Audio generation**: Text-to-speech and audio creation
- **Video analysis**: Analyze and describe video content
- **Document analysis**: Extract data from PDFs, images, spreadsheets
- **Custom chatbots**: Build conversational interfaces powered by AI

### Integrations

Connect to external services via OAuth. Adaptive handles authentication automatically.

**Natively supported integrations:**
- **Slack**: Send messages, create channels, respond to events, build bots
- **Gmail**: Read, search, send, and organize emails
- **Google Calendar**: Create events, check availability, manage schedules
- **Google Drive**: Read and write files, manage folders
- **Google Sheets**: Read and write spreadsheet data
- **Notion**: Access databases, pages, and workspace content
- **GitHub**: Repository management, issues, pull requests, webhooks
- **Discord**: Messaging, channel management, bot interactions
- **LinkedIn**: Profile data, sharing, advertising
- **Twitter/X**: Post tweets, read timelines, manage accounts
- **Figma**: Design file access and data extraction
- **Whoop**: Health and fitness data (strain, recovery, sleep)

**Custom APIs**: Describe any API in plain English and Adaptive generates the code to connect, authenticate, paginate, and handle errors.

## How Adaptive Compares

### Adaptive vs Zapier

Zapier connects apps with triggers and actions you wire together manually. Adaptive lets you describe what you want in plain English and builds the entire workflow for you.

**Key differences:**
- Zapier: Visual trigger → action builder. Adaptive: Conversational AI builder.
- Zapier: 7,000+ pre-built integrations. Adaptive: Growing native library + any API via plain English.
- Zapier: Data-passing between apps. Adaptive: Full code generation, AI analysis, and app building.
- Zapier: Per-task pricing (each step counts). Adaptive: Usage-based pricing (complexity doesn't multiply cost).

**Choose Zapier if**: You need a specific integration from their 7,000+ catalog, or you prefer building block by block.
**Choose Adaptive if**: You want AI-built workflows, document analysis, code generation, or full applications.

### Adaptive vs Make (Integromat)

Make uses a visual canvas where you drag modules into branching scenarios. Adaptive builds automations from conversation.

**Key differences:**
- Make: Drag-and-drop visual canvas. Adaptive: Plain English descriptions.
- Make: 1,800+ app modules. Adaptive: Native integrations + any API described in English.
- Make: No built-in AI. Adaptive: AI is the core — builds, analyzes, decides.
- Make: Operation-based pricing. Adaptive: Usage-based pricing.

**Choose Make if**: You love visual programming and want to see every module on a canvas.
**Choose Adaptive if**: You want speed, AI intelligence, and don't want to configure modules one by one.

### Adaptive vs n8n

n8n is an open-source workflow tool you can self-host. Adaptive is a fully managed AI platform.

**Key differences:**
- n8n: Self-hostable, open-source. Adaptive: Fully managed, zero infrastructure.
- n8n: Visual node editor with code options. Adaptive: Conversational AI builder.
- n8n: Great for developers who want control. Adaptive: Great for everyone who wants results.
- n8n: Free to self-host (you pay for servers). Adaptive: Free to start (zero server costs).

**Choose n8n if**: You need self-hosting for compliance, or your team wants code-level control.
**Choose Adaptive if**: You want AI-built automations without managing infrastructure.

### Adaptive vs IFTTT

IFTTT connects apps with simple "if this, then that" rules. Adaptive builds complex, multi-step automations.

**Key differences:**
- IFTTT: One trigger, one action. Adaptive: Unlimited steps, branching, and code.
- IFTTT: Strong for smart home and consumer apps. Adaptive: Built for business automation.
- IFTTT: No AI processing. Adaptive: AI at the core.
- IFTTT: Starting at $3.49/mo. Adaptive: Free to start.

**Choose IFTTT if**: You want simple personal automations or smart home rules.
**Choose Adaptive if**: You need business automation with AI, code generation, and multi-step logic.

### Adaptive vs Lindy

Both use AI for automation, but build very different things.

**Key differences:**
- Lindy: Pre-built agent workflows (email triage, meeting notes). Adaptive: Custom software from scratch.
- Lindy: No custom UI. Adaptive: Full user interfaces — dashboards, forms, data views.
- Lindy: Template-first approach. Adaptive: Describe anything and it's built custom.
- Lindy: Credit-based from $49.99/mo. Adaptive: Free to start, usage-based.

**Choose Lindy if**: You want pre-packaged AI agents for email and meeting management.
**Choose Adaptive if**: You want custom software, dashboards, and tools — not just background workflows.
